# 프론트 웹 서버

**기술 스택**

- node 18.17.x
- npm 10.7.x

## 서버 실행 방법

### 의존성 설치

```shell
npm i
pnpm install
```

### 서버 실행

```shell
npm run dev
pnpm run dev
```

### 빌드 실행

```shell
npm run build
pnpm run build
```
